jFlix Support

Welcome to jFlix support.

jFlix is a media player that allows you to import and organize your own authorized M3U playlists and play supported live streaming channels.

Getting Started

1. Import an M3U Playlist

Open the M3U import screen and enter the URL of an M3U playlist that you are authorized to access.

2. Select a Category

You can organize imported channels into categories including:

  • Cricket
  • Football
  • Bangla
  • English
  • News
  • Weather
  • Cartoon
  • Others

3. Filter Channels

Use the filter option during M3U import to import only channels whose name or streaming URL matches your search.

For example, searching for "Sports" can help locate channels containing that term.

4. Set the Import Limit

You can specify how many channels you want to import.

5. Play a Channel

Select a channel from Live TV to start playback. Playback depends on the availability and compatibility of the streaming source.

Channel Logos

jFlix displays channel logos when a valid logo URL is provided by the imported M3U playlist.

If a playlist does not provide a valid logo URL, a default television icon may be displayed instead.

Favorites

You can add channels to your Favorites for easier access. Favorite information is stored locally on your device.

Channel Management

Channels imported into jFlix can be managed from the Live TV interface. You can remove channels that you no longer want to keep.

Playback Problems

If a channel does not play, try the following:

  • Check that your device has an internet connection.
  • Verify that the streaming URL is still active.
  • Try another channel from the same playlist.
  • Re-import the playlist if the source has changed.
  • Make sure the streaming provider permits access from your network.

Some streaming formats or servers may not be compatible with the device's media player.

M3U Import Problems

If channels are not imported:

  • Verify that the M3U URL is correct.
  • Make sure the URL is accessible from your device.
  • Make sure the playlist contains valid HTTP or HTTPS stream URLs.
  • Try importing a smaller playlist.
  • Check the filter if you are using one.

Important Information

jFlix does not provide television channels, IPTV subscriptions, or streaming content.

Users provide their own playlist URLs and are responsible for ensuring that they have the necessary rights and permissions to access and watch the content.
